# CrestOmen

CrestOmen is a high-performance, real-time processing engine that utilizes event-driven architecture to accelerate data pipeline execution.

CrestOmen is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CrestOmen.git`
2. `cd CrestOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
